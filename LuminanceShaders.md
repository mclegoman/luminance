# Shaders included with Luminance

> I generally turn **Fallback Over UI** on for shaders that make text difficult to read, and/or shaders that distort the screen making buttons hard to use. ^*dannytaylor*

## No Resource Packs Required
| Identifier         | Fallback Over UI | Fallback Under UI | Photosensitive | Notes                                                                                                                     |
|--------------------|------------------|-------------------|----------------|---------------------------------------------------------------------------------------------------------------------------|
| luminance:gaussian | true             | false             | false          | Obscures text when rendered over ui.<br/>Included with Luminance                                                          |
| minecraft:box_blur | true             | false             | false          | Obscures text when rendered over ui.<br/>Included with Minecraft                                                          |
| minecraft:creeper  | true             | false             | false          | Text is difficult to read on lower resolutions, it's fine at 1080p though.<br/>Included with Minecraft                    |
| minecraft:invert   | false            | false             | false          | It's slightly harsh on the eyes due to the inverted brightness, but it's still fully useable.<br/>Included with Minecraft |
| minecraft:spider   | true             | false             | false          | Renders screen in differing locations, making buttons hard to use.<br/>Included with Minecraft                            |
